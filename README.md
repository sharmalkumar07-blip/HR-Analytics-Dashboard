# HR Analytics Dashboard

## Project Overview
This project analyzes employee attrition data to identify workforce trends and support HR decision-making.

## Objectives
- Analyze employee attrition patterns
- Identify high-risk departments and job roles
- Study age and gender-based attrition trends
- Generate HR insights through dashboards

## Key Metrics
- Total Employees: 1470
- Employees Left: 237
- Attrition Rate: 16.12%

## Dashboard Insights

### Department-wise Attrition
Research & Development department recorded the highest attrition.

### Gender-wise Attrition
Male employees showed higher attrition than female employees.

### Age-wise Attrition
Employees aged 29–31 experienced the highest attrition.

### Job Role-wise Attrition
Laboratory Technicians and Sales Executives recorded the highest attrition levels.
